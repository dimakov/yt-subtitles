# Subtitle Downloader for YouTube

A Microsoft Edge extension (Chromium Manifest V3, so it also runs in Chrome)
that downloads the subtitles of the YouTube video in the current tab.

- Uploaded subtitles and auto-generated captions, in every language the video offers
- YouTube's auto-translation into any of its supported languages
- SRT, WebVTT, plain text (optionally with `[m:ss]` timestamps) or JSON
- Download to a file or copy to the clipboard
- Works on watch pages, Shorts and live replays on `www.youtube.com` and `m.youtube.com`

Files are named `<title> [<video id>].<language>.<ext>`, the same pattern yt-dlp
uses, so video players pick the subtitles up next to a downloaded video.

## Install in Edge

1. Open `edge://extensions`.
2. Turn on **Developer mode**.
3. Click **Load unpacked** and choose the `extension` folder of this repository.
4. Pin **Subtitle Downloader for YouTube** from the puzzle-piece menu.

Tabs that were already open on YouTube work too: the popup injects its page
script on first use.

## Use

Open a video, click the toolbar icon, pick a subtitle track, optionally a
language to translate to, and a format, then press **Download** or **Copy**.
The popup remembers the last format, timestamp choice and translation language.

For translations (and for tracks the player has not loaded yet) the extension
may briefly turn the player's CC button on and back off. That makes the player
issue its own signed caption request, which the extension then reuses.

## How it works

YouTube's web player now signs every caption request with a proof-of-origin
token, and unsigned requests come back empty. The extension's page script
(`extension/page/page-api.js`, running in the page's own JavaScript world) gets
subtitles in this order:

1. Reuse the token from a caption request the player already made (seen through
   the Resource Timing API; nothing is patched).
2. Ask YouTube's Innertube player API as the Android or iOS app, whose caption
   links need no token.
3. Toggle CC so the player makes a fresh signed request, then reuse that token.

Translations try step 3 before step 2, because YouTube rate-limits unsigned
translation requests. The full design is in
[docs/hld/subtitle-download.md](docs/hld/subtitle-download.md).

Nothing leaves the browser except requests to youtube.com. The extension has no
analytics and no server.

## Develop

```
extension/            the unpacked extension (load this folder)
  manifest.json
  page/page-api.js    YouTube page bridge: track list, tokens, fetching
  lib/captions.js     json3 timed text -> cues
  lib/formats.js      cues -> SRT / VTT / TXT / JSON, file names
  popup/              toolbar popup UI
  icons/              generated by scripts/make_icons.py
tests/                node:test suites and synthetic fixtures
scripts/              icon generator and release packager
docs/hld/             design documentation
```

- `npm test` runs the unit tests (Node 20 or newer; no dependencies).
- After editing popup or library code, reopen the popup. After editing
  `page/page-api.js` or the manifest, click **Reload** on `edge://extensions`
  and reload the YouTube tab.
- For debugging, the popup can be opened as a page aimed at a specific tab:
  `chrome-extension://<extension id>/popup/popup.html?tabId=<tab id>`.
- `npm run icons` redraws the icons (needs Python with Pillow).
- `npm run package` writes `dist/subtitle-downloader-for-youtube-<version>.zip`
  for the Edge Add-ons store. It never overwrites an existing archive, so bump
  `version` in `extension/manifest.json` for each release.

  - Regenerate the logo with `npm run icons`.
  - Regenerate the rest with `node scripts/capture_store_images.mjs`, using
    Windows Node 22+ with Edge installed. It renders the real popup with the
    invented demo data in `store/src/`, in a throwaway headless Edge profile
    with sync turned off.

## Limitations

- Videos that need sign-in (age-restricted, members-only, private) work only
  through the token path, which needs the player to show captions for them.
- Live streams have no downloadable captions until YouTube finishes processing.
- The extension depends on undocumented YouTube internals: the json3 timed-text
  format, the Innertube player API and the player's CC button. If YouTube
  changes them, `page/page-api.js` is the file to update.
